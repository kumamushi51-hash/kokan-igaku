# 腹証奇覧 腹証図・症状検索アプリ — 作業手順書

利用者：栗原智先生（富山大学附属病院 和漢診療科）。稲葉文礼『腹証奇覧』を図ごとに翻刻・現代語訳し、腹証図つきで症状から検索できるアプリにする。
類聚方広義アプリ（ruijuho/）と同じ作り。同じリポジトリの `fukusho/` フォルダ。

  - 当初の RB00004915（正編・後編のみ1冊）から利用者の指定で変更（2026-11-21）

  - 撮影位置はコマごとに違う。頁と枠の位置は work/pages.py が自動で求める（紙の黄みで本の範囲、その中央をのどとする）

- work/make_figs.py：data の fig.src（img/fig_コマ頁.jpg）を原本から枠線を検出して切り出し → ../img/。`python3 fukusho/work/make_figs.py`（引数なしで data にある図をすべて作る）。「枠を検出できず頁全体で切り出し」と出たら切り出し結果を目で見て、図が欠けていれば make_figs.py の BOX に範囲（原画像座標）を追記して作り直す（頁全体のままでも可）
- work/data/data_NN.js：window.FUKU_DATA.push(...)。no は本書の図の順（総論などは kind:"総論"、no は直前の図と同じ番号に .5 などを使ってよい）
- work/app.src.html：アプリ本体（SYN＝現代語→古典語の言い換え辞書。類聚方広義のものを流用＋追加）
- work/build.py：data を結合 → work/fukusho.html（アーティファクト用）と ../index.html, ../sw.js（img/ をオフライン用に事前キャッシュ）

- work/notes/：翻刻メモ（画像は会話から消えるので、読んだらすぐ書く）

## まとめ方（桂枝湯で試作。利用者が了承し自動化を指示：2026-11-21）
1. 腹証図（fig）：src・コマ・図題（「〇〇湯之證」）・図の説明（desc：姿勢、彩色の部位など見たままを書く。解釈は本文に任せる）
2. 本文（paras）：段落ごとに head（見出し）・koma・kaki・yaku
   - kaki：原本の漢字カタカナ交じり文をひらがな交じりに改め、句読点を補う。漢字は原本の字体のまま。振り仮名は省く。本文中の漢文の引用は書き下す
   - yaku：現代語訳（全文）
3. 頭注（tochu）：枠の上の注。全文を kaki・yaku で
4. tags：現代語の症状・腹証。必要なら SYN に言い換えを追加
5. related：関連する図・総論の id
6. no は本書の図の通し番号（正編・後編・翼を通して 1, 2, 3 …）。group は「正編 上冊」「後編 上冊」「腹証奇覧翼 初編 上」など本書の表記に合わせる。一つの方剤に図が2つある（「二圖」「其二圖」）場合は1項目にまとめ、fig を figs:[...] の配列にしてよい（その場合 app.src.html を対応させる）
7. 判読に自信がない字、読みの迷い、通行本との異同は check（要確認）へ。推測で人名などを補わない

## 自動実行の1回分（20図）
- 引き継ぎメモの「次の作業位置」から 20図（図のない総論・序・凡例・附録などの頁は図数に数えない）
- 数図ごとに data → make_figs.py → build.py → commit → push（上限で止まっても進捗が残るように）。data は1回ごとに新しい番号のファイル（data_02.js, data_03.js …）
- 最後に playwright で確認 → アーティファクト更新 → 引き継ぎメモの「完了済み」「次の作業位置」を更新して push → 報告

## 1図の作業
0. crop.py で切り出して読み、翻刻を work/notes/ に書き留める
1. data ファイルに追記 → make_figs.py → build.py → playwright で fukusho/index.html を開き、エラーなし・図の表示・検索を確認
2. 引き継ぎメモを更新して commit → push（push 前に `git fetch --depth=5 origin main`、必要なら rebase）
3. アーティファクトを更新（fukusho.html に DOCTYPE・html・head を付けて index.html とし、img/ の図と一緒に publish_files）
