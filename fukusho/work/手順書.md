# 腹証奇覧 腹証図・症状検索アプリ — 作業手順書

利用者：栗原智先生（富山大学附属病院 和漢診療科）。稲葉文礼『腹証奇覧』を図ごとに翻刻・現代語訳し、腹証図つきで症状から検索できるアプリにする。
類聚方広義アプリ（ruijuho/）と同じ作り。同じリポジトリの `fukusho/` フォルダ。

  - 当初の RB00004915（正編・後編のみ1冊）から利用者の指定で変更（2026-11-21）
  - 11冊本に欠ける**後編 上**だけは RB00004915 のコマ82–121 で補う（work/images_b/v1/、コマ番号に b を付けて表す）。取得は同じワークフローの2つ目の手順
- work/images/v1/koma_XXXX.jpg：原本画像（XXXX＝RMDA ビューアの page 番号、11冊通し 1〜439、3000×2000px）。取得は .github/workflows/fukusho_images.yml（work/fetch_images.py）
  - 撮影位置はコマごとに違う。頁と枠の位置は work/pages.py が自動で求める（紙の黄みで本の範囲、その中央をのどとする）

- work/make_figs.py：data の fig.src（img/fig_コマ頁.jpg）を原本から枠線を検出して切り出し → ../img/。`python3 fukusho/work/make_figs.py`（引数なしで data にある図をすべて作る）。「枠を検出できず頁全体で切り出し」と出たら切り出し結果を目で見て、図が欠けていれば make_figs.py の BOX に範囲（原画像座標）を追記して作り直す（頁全体のままでも可）
- work/data/data_NN.js：window.FUKU_DATA.push(...)。no は本書の図の順（総論などは kind:"総論"、no は直前の図と同じ番号に .5 などを使ってよい）
- work/app.src.html：アプリ本体（SYN＝現代語→古典語の言い換え辞書。類聚方広義のものを流用＋追加）
- work/build.py：data を結合 → work/fukusho.html（アーティファクト用）と ../index.html, ../sw.js（img/ をオフライン用に事前キャッシュ）
- アーティファクト（同じ内容の閲覧用）：https://claude.ai/artifact/AKYhRfb19XzssV5UfDPQX8（slug 4b792b75-8c17-4be4-8d98-bdb97dd8b9bf。publish_files で index.html と img/ を送る）
- work/notes/：翻刻メモ（画像は会話から消えるので、読んだらすぐ書く）

## まとめ方（桂枝湯で試作。利用者が了承し自動化を指示：2026-11-21）
1. 腹証図（fig）：図は11冊本（RB00004916）の彩色のまま切り出して使う（利用者の指定）。彩色は色（青緑・藍など見たままの色）と部位（臍・心下・脇下などからの位置、向かって左右）を具体的に書く。src・コマ・図題（「〇〇湯之證」）・図の説明（desc：姿勢、彩色の部位など見たままを書く。解釈は本文に任せる）
2. 本文（paras）：段落ごとに head（見出し）・koma・kaki・yaku
   - kaki：原本の漢字カタカナ交じり文をひらがな交じりに改め、句読点を補う。漢字は原本の字体のまま。振り仮名は省く。本文中の漢文の引用は書き下す
   - yaku：現代語訳（全文）
3. 頭注（tochu）：枠の上の注。全文を kaki・yaku で
4. tags：現代語の症状・腹証。必要なら SYN に言い換えを追加
5. related：関連する図・総論の id
5b. **腹証所見（shoken）**（利用者の指定 2026-11-21）：本文・頭注・図の彩色から腹証の記載をすべて拾い、項目に振り分ける。
   表示位置：各頁の図の説明文の直後（利用者の指定）。図のない頁は本文の前。
   `shoken: [{ k: 項目, w: 原本の記載（kaki の語のまま、短く）, src: "本文"|"頭注"|"図", koma: "12R", note: 補足（任意）, sure: false（対応に解釈を含むとき） }]`
   - 項目 k は app.src.html の SHOKEN_CATS のどれか：腹力／腹直筋攣急／心下痞硬／胸脇苦満／心下悸／臍上悸／臍傍悸／臍下悸／臍傍圧痛点／S状結腸部圧痛／回盲部圧痛点／小腹不仁（以上が利用者指定の主項目）／心下痞／心下支結／胸満・胸痛／腹満／小腹急結／小腹硬満／小腹拘急／胃内停水（振水音）／腹皮拘急／塊・積聚／その他
   - 原文の語が項目名と同じか明らかに同じ所見（心下痞鞕→心下痞硬、胸脇苦滿→胸脇苦満、臍下不仁→小腹不仁 など）は sure を付けない。語の対応に判断を含むもの（拘攣→腹直筋攣急、「腹滑」「腹軟」「腹堅」→腹力、左臍傍・小腹左の圧痛や硬結→S状結腸部圧痛、右下の圧痛→回盲部圧痛点、動悸の部位の推定など）は sure:false にし、note に根拠を書く
   - 腹力は「軟・やや軟・中等度・やや充実・充実」のどれに当たるか、言える場合は **lv** に入れる（1段階なら "やや軟"、幅があれば ["やや軟","中等度"]）。言えなければ lv は付けない。根拠は note に
   - 左右がある所見（胸脇苦満・腹直筋攣急・臍傍圧痛点・臍傍悸など）は、本文か図で左右が分かれば **side**（"右"／"左"／"両"）を付ける。患者の右左で書く（図は向かって左＝患者の右）。分からなければ付けない
   - 本文が鑑別として「〇〇があれば別の方」と述べる所見（本方にはない所見）は **neg: true** を付ける。照合と一覧から除外され、表に「鑑別・本方になし」と出る
   - lv と side は「患者の腹証から探す」頁（#kensaku）の照合に使う。照合は shoken の項目（k）の一致で行うので、項目の振り分けを漏れなく行うこと
   - 図の彩色は部位を見たまま書く（例「臍の右上の藍色」）。本文にその部位の説明があれば対応する項目へ、なければ「その他」
   - 一つの方剤に同じ項目が複数あれば行を分ける。主項目に当たらない所見は追加項目か「その他」に入れ、新しい項目が繰り返し出てくるなら SHOKEN_CATS に足してよい（足したら引き継ぎメモに記す）
6. no は本書の図の通し番号（正編・後編・翼を通して 1, 2, 3 …）。group は「正編 上冊」「後編 上冊」「腹証奇覧翼 初編 上」など本書の表記に合わせる。一つの方剤に図が2つある（「二圖」「其二圖」）場合は1項目にまとめ、fig を figs:[...] の配列にしてよい（その場合 app.src.html を対応させる）
7. 判読に自信がない字、読みの迷い、通行本との異同は check（要確認）へ。推測で人名などを補わない

## 自動実行の1回分（30図）
- 引き継ぎメモの「次の作業位置」から 30図（図のない総論・序・凡例・附録などの頁は図数に数えない）
- 数図ごとに data → make_figs.py → build.py → commit → push（上限で止まっても進捗が残るように）。data は1回ごとに新しい番号のファイル（data_02.js, data_03.js …）
- 最後に playwright で確認 → アーティファクト更新 → 引き継ぎメモの「完了済み」「次の作業位置」を更新して push → 報告

## 1図の作業
0. crop.py で切り出して読み、翻刻を work/notes/ に書き留める
1. data ファイルに追記 → make_figs.py → build.py → playwright で fukusho/index.html を開き、エラーなし・図の表示・検索を確認
2. 引き継ぎメモを更新して commit → push（push 前に `git fetch --depth=5 origin main`、必要なら rebase）
3. アーティファクトを更新（fukusho.html に DOCTYPE・html・head を付けて index.html とし、img/ の図と一緒に publish_files）
