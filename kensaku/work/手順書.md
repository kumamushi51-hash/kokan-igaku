# 漢方 統合検索（kensaku/）— 手順書

利用者：栗原智先生（富山大学附属病院 和漢診療科）。腹証奇覧・類聚方広義・皇漢医学の3アプリのデータを統合し、
問診・診察所見や症例文（経過の記載）から、方剤選択の参考になる方剤を順位づけするアプリ。
公開：https://kumamushi51-hash.github.io/kokan-igaku/kensaku/

## 方針（利用者の指定）
- 4つ目のアプリとして独立させる（既存3アプリはそのまま）
- 入力は腹証だけでなく、一般的な漢方問診・脈・舌・腹証のすべて
- 症例文（経過の記載）を貼り付けて所見を拾う。**方式A＝端末の中だけで辞書照合**（外部送信なし・保存なし）。拾った所見は必ず確認画面で直してから検索する
- 結果には根拠（どの本のどの記述か）と各アプリへのリンクを必ず出す

## 構成
- work/load.js：3冊の data_*.js を読み込む
- work/names.js：方剤名の正規化（旧字→新字）と別名（ALIAS）。題名を主の方剤・附の方剤・別名に分ける。対応漏れは ALIAS に1行足す
- work/findings.js：所見辞書（約270項目）。1行＝`ID|分類|表示名|言い換え|病態の手がかり`。腹証奇覧の shoken 項目との対応（SHOKEN_MAP）と、腹力の原文から充実／軟弱を判定する関数もここ
- work/extract.js：症例文の解析（ブラウザと node 共通）。否定（なし・（−）・認めず）、経過（消失・改善）、腹証の左右、脈の連続表記（脈沈細弱）、舌の色、腹力◯/5、正常表現（薄白苔・淡紅舌）の除外、受診ごとの区切り（初診・再診・◯週後・日付）、主訴の行に★
- work/app.src.html：アプリ本体（症例文／所見／結果／方剤／使い方）
- work/build.js：索引を作って組み立てる → ../index.html, ../sw.js（Pages 用）, work/kensaku.html（単体版）, work/notes/未対応タグ.txt

## 組み立て
`node kensaku/work/build.js`（`--stats` で件数だけ表示）
- 皇漢医学などのデータが増えたら、そのたびに実行して commit すれば検索に反映される（皇漢医学の自動作業の最後にも実行する）
- 辞書を足したら work/notes/未対応タグ.txt を見て、臨床で意味のあるタグが残っていないか確認する（病名・治療状況は残ってよい）

## エキス剤の印
- 保険診療で処方できる医療用エキス製剤がある方剤に「エキス」の印。結果では「エキス剤のある方剤だけ表示」で絞れる
- 対応表は work/names.js の EXTRACT（正式名→製剤名、同名なら空）。3冊に出る方剤だけ。PMDA の医療用医薬品情報で確認（2026-11）
- 一般用（OTC）しかないもの（竹葉石膏湯・葛根黄連黄芩湯など）は載せない。薬価収載の変更があれば EXTRACT を直す

## 症例報告（日本東洋医学雑誌）
- 利用者の指定で、日本東洋医学雑誌（J-STAGE、フリーアクセス、学習目的の利用は可）の臨床報告を4つ目の根拠（J＝「誌」）として加える。まず最新の号で試作（2026-11-26：77巻1・2号、11本15症例）
- 本文PDFは J-STAGE の robots 設定で自動取得できない（回避しない）。論文ページの抄録を WebFetch で読み、症例ごとに事実（年齢・性別、診断、所見、証、方剤と効果）を**自分の言葉の短い語句**で work/cases/jsom_vNN.js に書く。抄録の文章は引用しない
- 目次：https://www.jstage.jst.go.jp/browse/kampomed/<巻>/<号>/_contents/-char/ja、論文：…/article/kampomed/<巻>/<号>/<巻>_<頁>/_article/-char/ja
- 有効（一部有効）の方剤に、その症例の所見を根拠として付ける。無効の記録は方剤の画面に表示だけする。併用・加減は rx[].note に書く（加減方はもとの方剤名で）
- 方剤名が具体的に書かれていない報告（「四物湯含有方剤」など）は入れない
- 古典にない後世方も方剤として入る。保険収載のエキス剤があれば names.js の EXTRACT に足す。新しい所見の語は findings.js に足す

## 根拠の取り方
- 類聚方広義：tags、主治の現代語訳、条文の書き下しの脈
- 皇漢医学：tags、腹証の論（腹証の所見のみ）、条文の書き下しの脈
- 腹証奇覧：shoken（整理済みの腹証所見、左右つき）、tags
- 「禁忌：」で始まるタグは禁忌として扱う

## 点数（app.src.html の scoreOne）
- 一致した所見ごとに idf（ln(1+方剤数/その所見を持つ方剤数)）× 分類の重み（腹証1.5・脈1.3・証0.8・病名0.6・他1.0）× 本の数（1+0.3×(冊数−1)）
- 腹証の左右：同側 ×1.2、反対側のみ ×0.6／主訴★ ×2／条文の書き下しにしか出ない脈 ×0.6
- 方剤ごとの所見数で割り引き（÷(1+0.015×所見数)）、禁忌に当たれば ×0.7
- 重みを変えたら使い方タブの説明も直す
